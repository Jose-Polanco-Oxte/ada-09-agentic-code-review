## Reflexiones Generales

1. **Procedimiento vs Herramienta:** Una Agent Skill no es una herramienta externa ni una API; es el "know-how" empaquetado que le enseña al agente cómo razonar y operar sobre un flujo de ingeniería específico.
2. **Progressive Disclosure:** Separar el contenido en `references/` y `scripts/` evita saturar la ventana de contexto del agente. La skill solo lee el checklist o la guía de severidad cuando realmente entra a la fase de inspección.
3. **Shift Intelligence Left:** Dejar la comprobación estructural del reporte a un script en Python (`validate_review_report.py`) es infinitamente más confiable y económico que pedirle al modelo de lenguaje que "recuerde" no olvidar secciones.
4. **Higiene de Dependencias:** Instalar skills de terceros exige el mismo cuidado que instalar paquetes de npm o pip: auditar el código fuente, congelar el commit (*pinning*) y limitar los permisos de ejecución para proteger la cadena de suministro de software.
